# 全流程 Codex 聊天

打开业务项目后，工作台、内容库、素材库、发布日历、发布记录、账号与定位、设置与备份，以及内容编辑页，右侧均显示 Codex 助手。默认浅色，右上角可收起或展开；主页会随可用宽度调整布局。

## 从选题开始

默认“对话范围”为 **项目对话 · 从选题开始**。空项目也能直接发送，例如“结合账号定位，帮我策划 5 个选题”。无需先新建内容或添加平台版本。切换页面后仍在同一个项目对话中，助手会获得发起本轮时的页面名称、账号定位及当前项目的内容、素材和排期摘要。

项目资料是参考信息，不会自动变成发布指令。助手根据实际问题讨论或执行；讨论回复保存在聊天记录中，不会自动覆盖平台正文。确定选题后，可使用页面上的“新建内容”，再继续准备平台版本。

## 项目对话与主题对话

- 项目对话贯穿整个工作流程，适合定位、选题、素材整理、整体计划和复盘。
- 在“对话范围”选择一个内容主题，可继续该主题原有的对话。选择“起草版本”并指定平台版本后，结构化文案写回所选版本，继续使用版本冲突检查。
- 切换页面不会切换所选对话范围；面板显示当前页面与当前项目，便于核对上下文。
- 同一项目内，未发送输入按对话范围暂存，切换页面或收起聊天栏不丢失。它们不是已保存记录，退出应用或切换项目后需重新输入。已发送的对话记录保存在本地项目内，重启后可继续。
- 不同项目、不同主题以及不同 Codex 登录账号使用独立的模型会话，旧的主题记录保持可查看。

按 **Enter** 发送，**Shift+Enter** 换行；中文输入法确认候选词不会触发发送。发送失败时保留输入，运行中的对话可停止。模型、思考强度和 Full Access 设置沿用原有功能。只读项目可查看记录，不能发起任务。

## 实现与验证

项目任务不依赖内容 ID。任务与上下文保存在 `.content-workspace/ai-runs/`，历史与模型线程映射保存在项目本地索引中。上下文只选取当前项目的资料；内容、素材、发布任务分别最多提供 40、100、30 条摘要，不自动携带全量媒体或网页登录凭据。模型仍可按用户要求通过原有 Full Access 工具读取文件。

常规自动化使用模拟 Codex 响应，覆盖空项目开始、页面与主题切换、输入保留、流式回复、发送失败、重启续聊、停止任务、项目隔离与只读限制。真实 Codex 核对命令如下，会使用当前账号额度：

```powershell
npm run verify:project-chat
```

该命令在忽略的 `.local/project-chat-verification/` 新建隔离项目，通过两轮短对话检查跨页面记忆及同一线程复用；不需要创建内容、不执行发布，也不修改日常业务项目。
