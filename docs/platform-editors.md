# 平台与外观设置（dev 分支）

在仓库目录运行 `npm run dev` 使用本次更新，无需打包。既有安装包不随源码更新。

创建自定义平台后，请继续使用更新后的开发版打开项目；旧安装包的平台列表固定，无法识别自定义平台。

## 新增和编辑平台

打开项目，在“账号与定位 → 平台管理”或“设置与备份 → 平台管理”中点击“新增平台”，填写名称、颜色并选择编辑方式。点击已有平台旁的编辑按钮可修改这些设置。

登记平台账号、添加内容版本时，平台下拉框旁也有“新增平台”和“编辑当前平台”。在这里新增后会自动选中新平台，不用退出当前表单。名称不能为空，重名时会提示选择已有平台。

默认已提供“微信公众号”，与“微信群”是两个独立平台。登记公众号账号后，添加实际发布目标，再创建微信公众号内容版本即可准备文章和发布包。

配置用于当前项目，保存到项目的 `.content-workspace/platforms.json`，随项目备份与恢复。平台标识保持固定，改名不会断开账号、内容、发布任务的关联。旧项目无需手动迁移；修改前使用内置默认列表，只读项目可以查看。更换编辑方式不会删除旧稿字段。

## 各平台的编辑界面

| 默认平台 | 编辑方式 | 界面差异 |
| --- | --- | --- |
| X | 帖子 | 直接写正文，附件在后；时间线卡片预览；内部名称折叠，不作为公开标题；不显示封面按钮 |
| 小红书 | 图文笔记 | 图片与封面优先，独立标题、正文和话题；图片轮播预览；选择封面时把该图片移到首位 |
| 微信公众号 | 长文章 | 标题、作者、摘要、正文、原文链接；小标题、加粗、引用、列表快捷操作；文章排版与封面预览 |
| YouTube | 视频 / Shorts | 视频与 Shorts 切换横屏 / 竖屏预览，两者都有标题和关键词；可见性、是否面向儿童、播放列表；普通视频支持章节时间轴 |
| B站 | 视频投稿 / 图文动态 | 投稿提供自制 / 转载、来源、分区、合集；动态使用正文与附件，收起投稿字段和公开标题 |
| 抖音 | 短视频 / 图文作品 | 短视频预览或图片轮播；作品描述、话题、位置、封面文案；切换后保留关联素材并提示类型不匹配 |
| Instagram | 帖子轮播 / Reel / Story | 轮播与图片替代文字、Reel 视频预览、Story 竖屏逐张预览和进度条；位置独立填写 |
| Facebook | 图文 / 链接 / 视频 Reel | Facebook 点赞、评论、分享式预览；链接地址、卡片标题备注与可见范围；链接自动加入发布正文 |
| Discord | 频道消息 / 论坛帖子 | 频道消息样式；论坛独立标题与标签；加粗、行内代码、代码块、剧透遮罩快捷输入和基础预览 |
| 微信群 | 群消息 / 群公告 | 群消息气泡或公告标识；按空行拆分文字，编排媒体与链接，逐段复制；公告素材作为补充群消息准备 |

自定义平台可从七种基础编辑方式中选择，内置平台也可以修改方式。上表的专用“发布类型”位于版本编辑器顶部，各版本独立保存。切换发布类型会保留已填写的隐藏字段与关联素材，切回后继续编辑。若在平台管理中主动把内置平台改为另一种基础编辑方式，则优先采用你的设置，暂不展示该平台的专用选项。

## 使用平台专用选项

1. 打开内容主题，切换到需要的平台版本；没有该版本时点击“添加版本”。
2. 在编辑器顶部选择“发布类型”，如 YouTube → Shorts、B站 → 图文动态、Instagram → Story。
3. 填写该类型的字段，选择媒体，在右侧查看内容预览和发布信息。内部名称用于管理，不会作为普通帖子的公开标题。
4. 点击“保存草稿”。确认内容后标记就绪、安排任务，再导出人工发布包。

YouTube 章节单独填写，导出时追加到视频简介；切换 Shorts 会保留章节草稿，但不追加章节。章节提示检查首个时间为 `00:00`、至少三行、递增且相邻间隔至少十秒。最后一章时长和账号资格仍需在 YouTube 确认。

Instagram 图片替代文字绑定到素材 ID，调整轮播顺序不会串到其他图片。发布包会列出替代文字与对应文件名。Story 的配文作为制作备注，音乐、贴纸、链接贴纸等在平台内添加。短视频和 Reel 的预览不会改写或裁切原始视频。

Facebook 链接卡片不联网抓取网页；标题输入是本地备注，实际卡片由 Facebook 读取网页信息后生成。可见性、分区、合集、位置等设置用于发布准备，不会自动改动平台账号设置。抖音封面文案用于预览与制作备注，不会写入原始图片。

微信群与 Discord 点击“按空行拆分正文”，可把多个段落变成独立消息，媒体保留在末尾。点击“文字段”或“链接”开始手动编排时，也会先保留现有正文和媒体。已自定义后，下方消息段就是发送内容；上方正文作为底稿，不会覆盖你在消息段里的修改。文字或链接旁的复制按钮可逐段复制，重复点击“加入已选媒体”不会重复添加已有附件。

X 当前提供单条帖子编辑，不包含串帖、投票或 X Articles 专用流程。公众号正文保存为 Markdown 草稿，预览支持基础排版；粘贴到公众号后台后仍需检查最终样式。本地预览不承诺与平台客户端像素一致，也不会据此判断账号资格或自动发送。

作者、摘要、原文链接、封面及平台专用字段会随版本保存并进入发布快照，也支持版本历史恢复。导出包的 `发布信息.md` 列出对应字段，`正文.md` 保存组合后的发布正文（包括适用的章节、链接、话题），`发送顺序.md` 列出消息和素材。自定义消息段以 `发送顺序.md` 为准。发布任务使用安排时的快照；之后修改平台名称、发布类型或草稿不会覆盖既有快照。Codex 的生成上下文包含平台名称、当前发布类型、编辑方式和专用字段。

## 浅色、深色和跟随系统

默认使用浅色主题，即使 Windows 处于深色模式也保持浅色。在“设置与备份 → 外观”选择：

- **浅色（默认）**：白色面板、深色文字。
- **深色**：手动使用深色面板。
- **跟随系统**：随着系统明暗设置切换。

选择会立即生效并保存在本机应用设置中，重启后恢复，不影响 Codex CLI 路径配置。

## 设计依据

X 官方说明把普通帖子定义为文字与照片、视频、链接等内容；本地帖子编辑因此采用正文在前、附件在后的方式。[X 发帖说明](https://help.x.com/en/using-x/how-to-post)

小红书官方分享 SDK 将笔记分为图文与视频，分别携带标题、正文和对应媒体。本版默认图文编辑突出图片、标题与正文。[小红书分享开放平台](https://agora.xiaohongshu.com/doc/harmony)

YouTube 官方上传流程分别填写标题、简介和缩略图，因此视频编辑提供这些独立字段。[YouTube 上传视频说明](https://support.google.com/youtube/answer/57407?hl=en)

YouTube 的手动章节放在简介中，并要求首个时间戳为零、至少三个递增时间戳、每章至少十秒。本地章节输入和提示据此设计。[YouTube 章节说明](https://support.google.com/youtube/answer/9884579?hl=en)

B站区分自制与转载投稿。本地提供相应选择和来源备注，不替用户判断作品归属。[B站投稿规范](https://member.bilibili.com/studio/convention/content?index=3-1&navhide=1)

抖音官方分享流程支持图片和视频，本地据此分开准备图文作品与短视频。[抖音分享文档](https://open.douyin.com/platform/resource/docs/develop/share/android)

Instagram 官方分别介绍 feed 图片、轮播、Reels 和 Stories；本地提供对应的媒体预览与制作备注。[Instagram 创作功能](https://about.fb.com/news/2023/11/new-ways-to-create-content-on-instagram/)

Facebook 宣布新视频逐步统一使用 Reels 发布流程，故本地使用“视频 / Reel”入口。[Facebook 视频发布更新](https://about.fb.com/news/2025/06/making-it-easier-create-videos-facebook/amp/)

Discord 论坛帖支持标题和标签，频道文字支持 Markdown。本地论坛与频道编辑分别保留这些差异，预览支持其中常用格式。[Discord 论坛说明](https://support.discord.com/hc/en-us/articles/6208479917079-Forum-Channels-FAQ)、[Discord Markdown 说明](https://support.discord.com/hc/en-us/articles/210298617-Markdown-Text-101-Chat-Formatting-Bold-Italic-Underline)

以上资料用于确定编辑结构。各平台的投稿资格、内容类型、数量与长度限制仍以实际投稿界面为准，本应用不硬编码未经账号验证的限制。
