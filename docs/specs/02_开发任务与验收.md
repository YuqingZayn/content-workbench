# 账号项目内容工作台：开发任务与验收

日期：2026-09-07。配套 [产品与技术实施方案](01_产品与技术实施方案.md)。第一个本地闭环已实现；以下复选框只标记完整任务验收，包含尚未全部完成的增强细项。逐项实际范围见 [工程任务进度](content-workbench/docs/roadmap.md)，证据见 [验收记录](content-workbench/docs/verification.md)。

本次完成：两个身份项目、真实图片/视频预览、四平台独立版本、Codex 真实多轮及图片上下文、固定快照、两群独立回填、UTC 排期、备份恢复、重启持久化、Windows 安装/便携构建与公开 GitHub 仓库。未进行真实社交平台发送。

## 1. 执行规则

按依赖从 M0 开始。每项任务完成后更新状态、实际代码路径、验证命令和结果。任务编号稳定，不因调整排期重排；范围变化记录在决策日志。

规格和原型不是人工审核关卡。已授权范围内的本地实现、修复和验证连续执行。需要真实平台账号、外部发送或付费服务时，先完成具体可查看的实现与测试，再按已有授权范围处理；缺少凭据时完成 Mock 与辅助流程，明确标记外部验证待完成。

所有参考项目先读所需模块，不默认整仓安装或引入代码。采用模块设计与实际复制代码分别记录；直接复用前核实对应文件、依赖和许可证。不得用某仓库的 README 支持表替代本产品实测能力表。

## 9. 验收用例目录

测试夹具使用明确可用的演示文字与素材，不放真实登录态。测试身份固定为“演示官号”“演示创始人”，名称本身不触发真实账号绑定。

| ID | 场景 | 预期结果 |
|---|---|---|
| AT01 | 打开已有中文路径、无 Git 的素材目录 | 正常建立项目，仅创建必要元数据，不移动原文件 |
| AT02 | 官号和 IP 项目来回切换 | 内容、账号、预览与会话归属一致 |
| AT03 | 目录只读、被移动或不存在 | 浏览／重连／定位提示；不清空项目 |
| AT04 | UI 与外部编辑器同时修改文案 | 保存冲突副本和双方内容，不静默覆盖 |
| AT05 | 写临时文件后强制退出 | 重启按日志恢复，不产生半成品正文 |
| AT06 | 文件替换成功但索引更新前退出 | 重启可重建一致索引 |
| AT07 | 移动整个项目并重新打开 | 内部相对路径有效；外部引用可重新定位 |
| AT08 | 复制／恢复同 projectId 的备份 | 明确复制或恢复模式；待执行队列暂停 |
| AT09 | 同文件重复导入 | 提示复用，不制造失控副本；原文件保留 |
| AT10 | 大文件复制中断、磁盘不足 | 清理临时副本或提供重试，未完成素材不可发布 |
| AT11 | 外部引用视频被删除或替换 | 标记缺失／已变化，不破坏已有快照 |
| AT12 | 2GB 视频拖动、无效 Range | 可用范围正常播放；非法范围正确返回，不整片入内存 |
| AT13 | 媒体 URL 换 projectId、路径穿越／链接越界 | 拒绝未授权文件读取 |
| AT14 | 同主题编辑中文小红书和英文 IG | 版本互不覆盖、媒体顺序独立 |
| AT15 | 向两个微信群导出三段消息 | 产生两个目标任务，消息顺序可追踪，导出不算已发 |

## 11. 投入估算、阻塞处理与交接

以一名熟悉 Electron／TypeScript 的工程师、运营人员持续提供样本为假设：M0 约 2–3 人日；M1 约 4–6 人日；M2 约 6–9 人日；M3 与 v0.1 包装约 4–6 人日；M4 已具备权限的平台约 8–12 人日。部分技术验证可与资料准备同时推进。合计约 24–36 人日，平台审核、采购和等待另计；这是详细范围后的估算，替代早期粗略周数，不作为承诺。

| 外部条件 | 可继续完成的工作 | 完成时如何标记 |
|---|---|---|
| Codex 未登录 | 连接层、事件回放、手动编辑与媒体 | AI 实测待完成 |
| 平台权限未获批 | 适配器接口、Mock、辅助发布、数据恢复 | 对应账号自动能力未验证 |
| IG 无媒体出口 | 本地预览、导出、容器流程 Mock | 自动提交禁用，辅助正常 |

| 普通微信群无官方通用接口 | 消息包、目标管理、人工回填 | 首版辅助发送即为设计完成 |

每个里程碑交接必须包含：可启动版本、变更列表、已完成任务号、验证证据、实际平台能力表、已知问题和下一项任务。任务打勾依据实际行为；Mock、未实现、等待权限、真实验证通过使用不同标识。
