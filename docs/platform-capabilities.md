# 实际平台能力

记录日期：2026-09-07。`verified` 指本应用的本地辅助路径完成测试，`unverified` 指未接入 / 未实测；不会把平台账号登记当作授权。当前没有账号令牌、发送权限或付费 API 配置。

| 平台 | 本地登记与发布包 | 目标区分 | 自动发送 | 外部权限 / 费用 / 配额 |
|---|---|---|---|---|
| X | verified | 主页账号 | unverified，未实现 | 未申请、未核实，不填旧套餐 |
| Discord | verified | 频道 | unverified，未实现 | Webhook / 频道权限待验证 |
| YouTube | verified | 频道 / 主页 | unverified，未实现 | 视频与社区接口分开验证 |
| Facebook | verified | Page / 个人 / 群目标分别登记 | unverified，未实现 | 具体 Page 权限待验证 |
| B站 | verified | 主页 / 频道 | unverified，未实现 | 动态与投稿分开验证 |
| 抖音 | verified | 主页 | unverified，未实现 | 账号资格与图文 / 视频权限待验证 |
| 小红书 | verified | 主页 | unverified，未实现 | 账号及客户端能力待验证 |
| Instagram | verified | 专业 / 个人账号类型分别登记 | unverified，未实现 | 专业账号、登录路线和媒体出口待验证 |
| 微信群 | verified | 运营身份 + 逐群目标 | unsupported（本版） | 普通群仅人工辅助，无内部群 ID 声明 |
| 微信公众号（dev） | verified | 公众号账号 + 发布目标 | 未实现 | 仅本地准备长文章与发布包 |
| 自定义平台（dev） | verified | 账号 + 独立目标 | 未实现 | 新增名称与编辑方式不构成平台授权 |

开发分支支持新增 / 编辑平台及七种编辑布局，见 [平台与外观设置](platform-editors.md)。配置随当前项目保存，不包含账号凭据。

发布包支持文案与有序媒体，包含固定 SHA-256 清单；不会推断某个平台允许的图片数量、付费资格、视频时长或账号发布能力。最终内容限制需要在真实平台预发布检查中核对。当前不提供凭据录入和自动发送按钮。

下一阶段按账号类型和内容类型逐项登记官方依据、权限、应用审核、收费、配额与验证日期，只有真实回执核验通过后才标记自动能力 verified。
