# 小红书网页登录 · 0.2.1 DEV

## 登录入口

1. 用 `npm run dev` 或上一级 `启动内容工作台.cmd` 启动最新版；升级后先保存并退出旧窗口。
2. 打开你的业务项目，进入 **账号与定位 → 网页登录**。账号页面右上角也有 **小红书网页登录** 快捷入口。
3. 如果还没登记小红书账号，填写账号名称，点击 **添加账号并登录小红书**。已有账号时，在下拉框中选中对应账号，点击 **登录小红书**。
4. 软件打开 [小红书官方创作服务平台](https://creator.xiaohongshu.com/login)。当前官网默认显示“短信登录”；可以点击登录卡片右上角的二维码图标切换扫码。手机号、短信验证码以及安全验证均在官方页面中完成。
5. 登录窗口开启期间会检查身份；也可以回工作台点击 **检查小红书登录**。只有官方身份响应成功才显示“已登录”，同时展示账号 ID 和可取得的昵称。

新增的账号名称是本地备注，不会创建新的小红书平台账号。已有小红书账号卡片上的 **登录 / 查看小红书** 可直接打开该账号的登录管理。

## 保留会话、换号与退出

关闭登录窗口会保留本机网页会话；重新打开会使用该项目、该账号的专用会话。重启软件后显示“会话已保存，待检查”，不能据此认定平台授权仍有效。

同一项目可以登记多个小红书账号，每个账号使用独立会话；不同项目也相互隔离，不读取或导入 Chrome、Edge 等其他浏览器中的登录信息。

换号时先点 **退出本机登录**，再重新打开登录页完成扫码。退出会关闭对应登录窗口，并清除这个账号在工作台中的 Cookie、网页存储、缓存和认证缓存，不影响其他账号或其他浏览器。它不代表撤销小红书在其他设备上的登录。

若登记的公开账号标识是 24 位小红书用户 ID，身份检查还会核对实际 ID；不一致时提示核对，避免把别的身份当成预期账号。

## 状态说明

| 状态 | 含义 |
|---|---|
| 未登录 / 等待网页登录 | 需要在官方窗口完成扫码或短信验证 |
| 已登录 | 最近一次官方身份检查成功 |
| 会话已保存，待检查 | 软件重启或检查超过 5 分钟，需要重新确认 |
| 登录已失效 | 官方身份检查明确拒绝旧登录，需要重新登录 |
| 网络异常 | 当前无法检查，原有会话保留 |
| 待确认 | 页面返回格式变化、权限或安全验证阻止了确认；打开官方页面检查 |
| 登录账号不一致 | 实际用户 ID 与登记 ID 不同，先核对再使用 |

加载失败时，检查网络并再次点击登录按钮；遇到验证码或平台安全验证时，在官方窗口处理。软件不绕过这些步骤。停用账号需要先启用后才能打开登录窗口，但仍可清除其本机登录。

## 存储与边界

会话由 Electron / Chromium 的独立持久分区保存，默认在应用用户数据目录的 `Partitions/` 下。状态与公开身份保存在 `web-logins/`，不保存密码或原始 Cookie。正常业务项目的备份、快照和发布包不包含这些应用用户数据；这两个目录也加入了 Git 忽略规则。不要把应用用户数据目录选作业务项目或手工上传。

官方窗口启用 sandbox、context isolation 和 web security，关闭 Node integration，不加载工作台 preload，不提供工作台 IPC。导航限定为明确列出的官方 HTTPS 站点，拒绝下载和额外设备权限。退出与检查按账号处理，并忽略退出前尚未返回的旧结果。

实现使用官方网站当前的只读身份请求 `/api/galaxy/user/info`；这是网页内部接口，并非承诺稳定的公开 OAuth API。格式变化时保留会话并显示“待确认”，不以存在 Cookie 或页面跳转作为登录成功的依据。Electron 分区与隔离依据见 [Session 文档](https://www.electronjs.org/docs/latest/api/session) 和 [安全指南](https://www.electronjs.org/docs/latest/tutorial/security)。

**本次新增的是网页登录和会话管理。小红书自动发帖尚未接入**；登录不会自动创建发布任务。文案编辑和辅助发布包继续使用原来的流程。
