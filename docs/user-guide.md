# 使用指南

## 开始工作

运行 Windows 便携版，或安装 Setup 后打开 Content Workbench。点击“打开本地文件夹”，选择已有素材目录，或在原生选择器里新建空文件夹。项目名称默认取目录名，原文件保持原位。

本次本地交付还可双击上级目录的“启动内容工作台.cmd”，直接运行 `release/win-unpacked/Content Workbench.exe`，无需自解压。上级目录“演示项目”内有演示官号和演示创始人，已包含真实 Codex 生成的草稿；其中发布结果明确标注为验收模拟，没有真实发送。

建议分别使用“品牌官号”“创始人 IP”两个文件夹。在“账号与定位 → 身份资料”填写定位、已确认事实、表达风格和时区。Codex 每次生成都会带入这些资料，测试示例不会自动出现在正式项目中。

## 素材与内容

素材库可选择文件、拖入文件 / 文件夹、粘贴截图。默认复制；大视频可选择引用。引用文件搬走后需要重新定位，内容不同的替代文件应作为新素材导入。移除登记保留源文件。

视频使用本机解码器，支持播放、暂停、拖动、音量。播放到所需时刻，点击“保存当前关键帧”。图片可按像素坐标裁剪，结果另存副本。未内置视频转码工具。

创建主题后，添加平台及语言版本。各版本独立维护正文、标题、标签、封面和有序媒体。微信版本可自定义文字、图片、视频和链接的消息段；未自定义时按正文与关联素材生成顺序。

点击“保存草稿”。切换页面 / 项目时尝试先保存；关闭有未保存内容的窗口会提示。外部文件修改发生冲突时显示双方内容并保留冲突副本。可从版本历史将旧内容恢复到编辑器，再保存为新版本。

## Codex

点击右侧“连接本机 Codex”。连接读取真实登录状态和模型目录；未登录请使用 CLI 的登录流程。可保持 CLI 默认模型，也可选择目录中的型号。

选择写入版本，输入需求。正在编辑的内容会先尝试保存，输入包含项目身份、事实底稿、选中图片 / 关键帧和素材清单。首版不把完整视频上传给模型。生成以只读线程运行，模型返回结构化提案，由应用校验后保存。

每次结果绑定发起时的项目、主题和版本；生成时切换项目不会改变归属。生成期间有编辑冲突时，提案保存为建议而不覆盖。可复制建议到编辑器合并。停止请求会等待 CLI 返回终态；关闭或断线不会自动重新提交。

## 排期与人工回填

先登记发送账号，再添加群、频道、主页或 Page 目标。这里保存的是用途和公开标识，不是平台授权。

保存草稿后，标记就绪。若同时修改了正文，第一次操作只保存新稿，再次标记就绪确认该版本。选择“安排发布”，勾选一个或多个同平台目标并填写人工截止时间。每个目标单独创建任务，正文和媒体被复制进固定快照。

“发布记录”中导出发布包，按 `发送顺序.md` 人工发布。导出不代表发送完成。随后回填实际发送人、时间、结果以及已发消息段；无公开链接的微信群可留空链接。只完成一部分段落时保留部分完成状态，完成的其他目标不受影响。

日历保存 UTC 时间并显示项目时区；时间输入明确标为本机时区，避免把海外墙上时间当作上海时间。人工任务到期后不会自动发送，电脑休眠后也不补发。

## 备份与恢复

设置中导出到项目外的空文件夹。可包含外部引用的媒体；未包含的路径列在 `backup-manifest.json`。备份不包含 Codex 登录凭据，包含本应用生成记录和会话 ID，因此请按业务文档保管。

恢复时选择备份和新的空目录，应用切换到恢复位置，保留原目录；所有未完成任务默认暂停。不要同时打开同一 projectId 的原目录和副本；移动项目后可通过“打开其他文件夹”重新定位。
